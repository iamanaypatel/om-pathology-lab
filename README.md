# Om Pathology Lab — Baxer, Unnao (Medical Diagnostics & WhatsApp Booking)

[![GitHub Pages Deployment](https://img.shields.io/badge/Live%20Website-GitHub%20Pages-success?style=for-the-badge&logo=github)](https://iamanaypatel.github.io/om-pathology-lab/)

A modern, responsive, and patient-first digital web platform for **Om Pathology Lab**, situated in Baxer, Unnao, Uttar Pradesh. Provides instant access to comprehensive diagnostic test menus, health checkup packages, transparent pricing, home blood sample collection booking, and direct instant WhatsApp dispatch.

## 🏥 Key Features

- **24/7 Diagnostic Center**: Complete lab operational details and emergency round-the-clock testing info.
- **Doorstep Blood Collection**: Seamless home sample pickup scheduling across Baxer, Bighapur, Unnao, and nearby villages.
- **Comprehensive Diagnostic Test Catalog**:
  - Complete Blood Count (CBC) with 24-parameter automated cell counter analysis
  - Lipid & Cardiac Profile (Cholesterol, Triglycerides, HDL, LDL, VLDL)
  - Liver Function Tests (LFT) & Kidney Function Tests (KFT / RFT)
  - Diabetic Screening (Fasting, PP Blood Sugar, HbA1c via Gold-Standard HPLC)
  - Thyroid Profile (Total / Free T3, T4, Ultrasensitive TSH via CLIA)
  - Vitamin D3 & B12, Iron Studies, Electrolytes & Infection Markers
  - Dengue NS1/IgG/IgM, Typhoid Widal & Typhidot, Malaria Antigen
- **Preventive Full Body Health Packages**: Basic, Executive, Senior Citizen, and Women's Wellness screening bundles with discounts.
- **Smart WhatsApp Booking Integration**: Interactive test selection cart generating instant, pre-filled WhatsApp booking messages with patient name, address, chosen tests, and preferred slot.
- **Patient Preparation Guidelines**: Clear fasting and preparation instructions in English and Hindi for accurate test results.
- **100% Mobile & Accessibility Optimized**: Built with responsive layouts, fast load speeds, touch-friendly navigation, and high-contrast readable medical typography.

## 🛠️ Built With

- **HTML5 & Vanilla JavaScript**: Clean, lightweight architecture with zero bloated runtime dependencies.
- **Tailwind CSS**: Modern medical UI palette featuring teal, emerald, and deep navy tones.
- **Inter Typography**: Clear, legible typography for medical reports and test parameters.
- **Font Awesome & Heroicons**: Polished medical iconography.
- **GitHub Pages & GitHub Actions**: Automated continuous deployment pipeline.

## 🚀 Local Development

To run or view this project locally:

```bash
# Clone the repository
git clone https://github.com/iamanaypatel/om-pathology-lab.git

# Navigate into the project directory
cd om-pathology-lab

# Open index.html in your default web browser
open index.html   # On macOS
# or start a lightweight HTTP server
npx serve .
```
